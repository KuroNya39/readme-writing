# readme-writing

面向非技术用户的 README / 用户指南写作范式（Claude Code Skill）。

先定读者画像，再按模块化骨架组织章节；行文结论先行、可扫读、措辞统一、界面文案用「」引用；附自检清单，要求文档精炼克制、配图与软件同步。

## 安装

```bash
# Skill 名 = 目录名 readme-writing
mkdir -p ~/.claude/skills/readme-writing
cp SKILL.md ~/.claude/skills/readme-writing/SKILL.md
```

装好后在对话里输入 `/readme-writing` 即可调用。

## 适用场景

- 新项目写第一版 README / 用户指南
- 旧文档乱、读者看不懂、需从开发者笔记改成用户文档
- 软件改了 UI / 流程 / 文案 / 数字后回来同步

## 目录

- `SKILL.md` —— 写作范式本体（章节骨架、行文规则、自检清单）
