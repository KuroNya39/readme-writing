# readme-writing

为软件项目撰写 / 重写 / 同步 README 与用户指南（Claude Code Skill，半自动文档工程师）。

AI 先替开发者把项目读明白：提取功能清单、推断读者、重建上手路径、审计数据与隐私、抄录界面文案原文，产出可溯源的《事实清单》；只把「只有开发者知道的取舍」抛给你判断（每题带推荐答案，可整轮回「全按推荐」）；再由读者心智推导结构、起草全文，校验后交付。

## 安装

```bash
# Skill 名 = 目录名 readme-writing
mkdir -p ~/.claude/skills/readme-writing
cp SKILL.md ~/.claude/skills/readme-writing/SKILL.md
```

装好后在对话里输入 `/readme-writing` 即可调用。

## 适用场景

- 新项目写第一版 README / 用户指南
- 旧文档乱、读者看不懂、需从开发者笔记改成用户文档
- 软件改了 UI / 流程 / 文案 / 数字后回来同步

## 工作方式

按 A–F 六个阶段推进，全程半自动：

- **A · 侦察取证** —— AI 读代码与运行画面，产出每条可溯源的《事实清单》。
- **B · 决策轮** —— 只把代码答不了、只有开发者知道的取舍抛出来，每题带推荐答案，可整轮「全按推荐」。
- **C · 信息架构** —— 按读者心智顺序推导章节，不套模板。
- **D · 写作** —— AI 起草全文：结论先行、可扫读、界面文案「」引用。
- **E · 校验** —— 可走通性 / 事实 / 文案 / 隐私 / 可读性自检，未通过不出稿。
- **F · 交付维护** —— 先骨架后正文；UI / 流程 / 文案变更后回取证同步受影响的节，文案改动要一次改齐所有副本、旧版公告不追改，交付逐行对照表。

## 目录

- `SKILL.md` —— 阶段 A–F 全文（取证清单、提问格式、写作规则、自检清单）
